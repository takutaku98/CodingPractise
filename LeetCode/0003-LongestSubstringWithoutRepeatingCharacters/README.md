# 3. Longest Substring Without Repeating Characters

## 問題

文字列 `s` の中から、同じ文字を含まない最長の部分文字列(連続した区間)の長さを求める。

- 例: `s = "abcabcbb"` → 答えは `3`(`"abc"`)
- 例: `s = "bbbbb"` → 答えは `1`(`"b"`)
- 例: `s = "pwwkew"` → 答えは `3`(`"wke"`)

## 解法: スライディングウィンドウ + 直近出現位置の辞書

### 素朴な解法との比較

一番単純なのは、開始位置と終了位置の全組み合わせ(部分文字列)を総当たりし、それぞれについて重複の有無を確かめる方法。部分文字列の数が O(n²)、重複チェックにさらに O(n) 前後かかるため、全体で O(n³) 〜 O(n⁴) になる(重複チェックの実装によってはもっと悪化する)。`s.Length` は最大 5×10⁴ まであり得るため、この方法では現実的な時間で終わらない。

この解法は「区間の右端を伸ばしながら、重複が起きたら左端だけを必要な分だけ前に進める」ことで、文字列を **1 回だけ** 走査して解く(O(n))。

### 核心となる発想

> 今見ている区間(ウィンドウ)`[left, right]` の中に重複がない状態を保ちながら、`right` を 1 つずつ伸ばしていく。もし新しく追加した文字がすでにウィンドウの中にあれば、重複が消えるところまで `left` を進める。

「ウィンドウの中にあるかどうか」を毎回全走査で調べると結局遅くなるので、`Dictionary<char, int>` に **各文字が最後に出現したインデックス** を記録しておき、重複が見つかったら `left` をそこへ一気にジャンプさせる。

### 各要素での処理

1. `right` を 1 つ進め、`s[right]` を見る
2. `s[right]` が辞書に記録されていて、かつその位置が `left` 以降(=今のウィンドウの中)なら、`left` をその直後まで進める
   - `left = Math.Max(left, lastIndex + 1)` — `Max` を使うのがポイント。単純に `lastIndex + 1` を代入すると、`left` が後退してしまうことがある(下記トレースの `right=3` 以降を参照)
3. `s[right]` の最終出現位置を更新する: `lastSeen[s[right]] = right`
4. 現在のウィンドウ長 `right - left + 1` で `maxLength` を更新する(**重複の有無に関わらず毎回更新する**のが重要)

### 具体例のトレース

`s = "abcabcbb"` の場合:

| right | s[right] | 直前の出現位置 | left | maxLength |
|---|---|---|---|---|
| 0 | a | (なし) | 0 | 1 |
| 1 | b | (なし) | 0 | 2 |
| 2 | c | (なし) | 0 | 3 |
| 3 | a | 0 | 1 | 3 |
| 4 | b | 1 | 2 | 3 |
| 5 | c | 2 | 3 | 3 |
| 6 | b | 4 | 5 | 3 |
| 7 | b | 6 | 7 | 3 |

最終的に `maxLength = 3`(`"abc"`)。

`right=6` の `b` は `right=4` で見た `b` の位置(4)を使って `left` を `5` に進めている。もし `Max` を使わず単純代入していたら、`"abba"` のようなケースで `left` が後退し、既にウィンドウから外れた文字を重複と誤判定したり、ウィンドウ長を過大に数えてしまう。

## ポイント

- **重複チェックを O(1) にする**: 「文字がウィンドウ内にあるか」を毎回全走査するのではなく、`Dictionary` で最終出現位置を持つことで判定を O(1) にしている
- **`left` は絶対に後退させない**: `Math.Max(left, lastIndex + 1)` がその保証。素朴に代入すると、辞書に残っている「ウィンドウ外の古い出現位置」を使って `left` を巻き戻してしまうバグを生む
- **記録は毎回行う**: 「重複が見つかった時だけ記録する」という発想だと、重複が一度も起きない文字列(例: `"abcdef"`)で記録が一件も残らず答えが求まらない。「区間を伸ばすたびに毎回記録する」ことで、この漏れを防いでいる
- `Dictionary` のインデクサ代入(`lastSeen[key] = value`)はキーの有無に関係なく上書きできる。`Add` メソッドは既存キーに対して呼ぶと例外を投げるので、更新が起こり得る場面では使えない

## 計算量

- 時間: O(n)(`n = s.Length`、各文字を 1 回ずつ処理)
- 空間: O(min(n, Σ))(`Σ` は文字種の数。辞書に入るのは同時にウィンドウ内にある文字種のみ)

### プロパティベーステスト(FsCheck)

ランダムな文字列に対して、返ってきた長さが「実際に `s` の中に存在する、重複なしの部分文字列の長さの最大値」と一致することを検証する。愚直な全探索(総当たり)で最大値を計算し、それを正解(オラクル)として比較する形のプロパティテスト。
